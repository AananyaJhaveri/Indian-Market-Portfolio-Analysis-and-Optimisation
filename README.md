# Indian Market Portfolio Risk Analysis & Optimisation

## Project Overview

This project performs quantitative analysis of Indian financial market instruments using Python. It evaluates historical returns, portfolio risk, asset correlations and portfolio performance, and applies portfolio optimisation techniques to identify an allocation with an improved risk-return profile.

The project combines financial data analysis, statistical risk measurement and portfolio simulation to demonstrate practical applications of Python in quantitative finance.

## Objectives

- Analyse historical market prices and calculate asset returns.
- Measure annualised returns and volatility.
- Examine relationships between assets using correlation analysis.
- Evaluate portfolio performance and downside risk.
- Simulate 10,000 possible portfolio allocations.
- Identify an optimised portfolio using risk-adjusted performance.
- Compare equal-weight and optimised portfolio strategies.
- Conduct Value at Risk (VaR), Conditional Value at Risk (CVaR) and stress-testing analysis.

## Technologies Used

- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib

## Methodology

### 1. Historical Market Data
Collect and analyse historical price data for selected Indian market instruments.

### 2. Return Analysis
Calculate daily returns and annualised returns to understand historical asset performance.

### 3. Risk Measurement
Calculate annualised volatility and examine the risk associated with individual assets and portfolios.

### 4. Correlation Analysis
Build a correlation matrix and visualise relationships between assets using a heatmap.

### 5. Portfolio Simulation
Generate 10,000 simulated portfolio allocations to examine different combinations of risk and return.

### 6. Portfolio Optimisation
Identify an allocation with the highest Sharpe ratio among the simulated portfolios and compare it with an equal-weight portfolio.

### 7. Risk Assessment
Evaluate portfolio downside risk using:
- Value at Risk (VaR)
- Conditional Value at Risk (CVaR)
- Maximum drawdown
- Stress-testing scenarios

### 8. Visualisation and Reporting
Present findings through charts, risk-return comparisons and portfolio allocation summaries. Export key analysis outputs as CSV files.
